# 达人雷达 · 增长引擎(Max 版)

给品牌市场团队的「主动发现层」:从全网频道池里把**下一个值得合作的中腰部达人**捞出来,每一分都说得清哪来的,并且有一条**能跑的自进化闭环**。

单文件、零依赖。**在线版:https://maxi-max-dev.github.io/growth-engine/**

## 四个页面

- 🏠 **总览**:达人雷达闭环(采集→打分→推荐卡→投放→回流→自进化)+ 盲测排名前三的新面孔
- 🎯 **达人雷达**([#radar](https://maxi-max-dev.github.io/growth-engine/#radar)):1,106 个真实 YouTube 频道的盲测回测。26 个已验证影石合作达人当标准答案(打分时隐藏),引擎把其中 6 个排进前 5% = 4.6× 随机基线。每张卡白盒可解释,带头像
- 📊 **数据回流**:26 个已验证合作达人 vs 引擎盲测排名的对照表 —— 闭环的燃料
- 🔁 **自进化**([#evolve](https://maxi-max-dev.github.io/growth-engine/#evolve)):在全池 1,106 条真数据上现场跑权重校准(带护栏的爬山),正例中位百分位 27.8% → 25.5%,前 5% 召回不许下降。**这是同类工具演示过但开源代码里没有的部分,这版做成了可运行的**

## 跑

```bash
cd growth-engine
python3 -m http.server 8752
# 浏览器打开 http://127.0.0.1:8752/index.html
```

## 数据与诚实说明

- 数据 = 2026-07-06/07 首轮盲测回测真实结果(yt-dlp 公开元数据 + bge-m3 本地 embedding,零 API 成本),不是编的样本
- demo 回流信号 = 已验证合作标签,同批标签上校准+评估有过拟合风险;真实部署回流信号 = 投放后转化数据,并用时间滚动验证。机制相同,页面演示的是机制
- 正式交付走官方开放平台 API(YouTube Data API / 星图 / 巨量 / RSS 企业源),**不上 cookie 爬**
- 打分引擎、可解释卡、自进化闭环与数据源解耦,换源不改核心
- 工作流骨架学自 engine.zcchr.com(飞书 AI 绝活大会展示),只取对命题有用的两环(回流 + 自进化);内容生产类模块(选题/文案/素材)与本命题无关,不包含
